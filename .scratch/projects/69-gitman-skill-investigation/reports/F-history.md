## Implications for the skill investigation

1. Test the rebase command against a workspace with an older local ancestor. The observed `-b @` result conflicts with the skill's unconditional instruction.
2. Check the default workspace tree before claiming that a verification run covers `main`. Report workspace cleanup as a required final check.
3. Keep the one-command warning in the skill. Test whether an agent still reaches for `gitman status` after reading it.
4. Define the gate policy for docs and data changes in the lifecycle owner. The observed skip preceded the current skill, so a current-skill behavior test must settle this point.
